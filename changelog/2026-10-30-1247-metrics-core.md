### 2026.10.30.1247

- Feat: an `Event` has `types`, values of the new `EventType` that plugin modules define, and typed `EventSettings` for each type through `with`
- Feat: a `Plugin` lists its `acceptedTypes`, and receives only events that share one by name; a plugin that lists none receives every event
- Feat: `shouldPublish` replaces `accepts`, and each plugin's `Snapshot` carries only its accepted types and their settings
- Feat: a plugin's `check` can refuse an event with `CatalogException` when its catalog or the plugin is added, so `add(Plugin)` now throws it
- Docs: requirements 0005 and 0008 with one test for each acceptance, and the README and architecture views name `EventType` and `EventSettings`
